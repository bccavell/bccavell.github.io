# Photos go here 📸

1. Drop your photos into this folder. Use simple names with no spaces,
   like `bday-1.jpg` or `skating.jpg`.
2. **Shrink them first.** Phone photos are often 4–8 MB, which makes the app
   slow on mobile data. Aim for about 1600px wide and under 500 KB. On a Mac,
   use Preview → Tools → Adjust Size. Online, use https://squoosh.app.
3. Point to them from `../data.js`:
   - Birthday gallery: `photos: [{ src: "photos/bday-1.jpg", caption: "..." }]`
   - A love note: `{ from: "Billy", date: "2027-01-05", text: "...", photo: "photos/skating.jpg" }`

⚠️ The site is public (but unlisted). Only add photos everyone's happy with.
